# Configuration Files

This directory contains configuration files for the Longitudinal Vehicle Control System.

## Files

- `default.yaml` - Default system configuration

## Configuration Parameters

### Vehicle Parameters

- `mass`: Vehicle mass in kilograms
- `resistance_coefficient`: Air resistance coefficient

### Simulation Parameters

- `time_step`: Simulation time step in seconds
- `max_time`: Maximum simulation time in seconds

### Control Parameters

- `max_traction_force`: Maximum traction force in Newtons
- `min_traction_force`: Minimum traction force (braking) in Newtons
